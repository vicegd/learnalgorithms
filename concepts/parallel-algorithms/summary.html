Summary: Parallel Algorithms

Everything on one page, to review the chapter before moving on.

Key ideas​

  • Processor frequencies stopped growing; performance now grows by adding cores (Concurrency and Parallelism).
  • Concurrency means dealing with several tasks whose executions overlap; parallelism means executing them at the same time on several processors.
  • Shared memory needs synchronisation; divide and conquer algorithms on independent parts of the data avoid most of the problems.
  • The Fork/Join framework runs divide and conquer in parallel: below a sequential threshold, solve directly; otherwise divide, solve the parts in parallel and combine (The Fork/Join Framework).
  • Parallelism does not change the asymptotic complexity, but it can divide the time by up to the number of processors (Performance of Parallel Algorithms).
  • Prefer a better algorithm before adding cores.

Fork/Join in Java​

Never join a task before starting the others.
