Proofs: Dynamic Programming

A dynamic programming algorithm is correct if its recurrence is correct: the optimal value of each subproblem must be obtained from the optimal values of smaller subproblems. This page proves the recurrences used in the lessons.

The 0/1 knapsack recurrence is correct​

Claim. The value V(i,j)V(i, j)V(i,j) defined by the recurrence of the lesson is the maximum value obtainable with the first iii objects and capacity jjj.

Proof. By induction on iii. For i=0i = 0i=0 there are no objects and the value is 0. For i>0i \gt 0i>0, consider an optimal selection SSS for (i,j)(i, j)(i,j). Either object iii is not in SSS, and then SSS is a selection of the first i−1i - 1i−1 objects with capacity jjj, so its value is at most V(i−1,j)V(i-1, j)V(i−1,j); or object iii is in SSS, and then S∖{i}S \setminus \{i\}S∖{i} is a selection of the first i−1i - 1i−1 objects with capacity j−wij - w_ij−wi​, so its value is at most V(i−1,j−wi)+viV(i-1, j - w_i) + v_iV(i−1,j−wi​)+vi​. In both cases the value is at most the maximum of the recurrence. Conversely, both options of the maximum correspond to valid selections. So the maximum is exactly the optimal value. ■\blacksquare■

This is the principle of optimality in action: the part of an optimal solution that concerns the first i−1i - 1i−1 objects is itself optimal for the capacity it leaves. Filling the (n+1)×(W+1)(n+1) \times (W+1)(n+1)×(W+1) table costs O(nW)O(nW)O(nW).
