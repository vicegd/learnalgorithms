Summary: Branch and Bound

Everything on one page, to review the chapter before moving on.

Key ideas​

  • Branch and bound explores the same implicit tree as backtracking, but generates all the children of a node and keeps the live nodes in a data structure (The Branch and Bound Scheme).
  • With a FIFO queue it is breadth-first; with a priority queue ordered by a heuristic it is best-first, and it can jump to the most promising node at any level.
  • Bounds are optimistic estimates. A node is pruned when its bound cannot beat the best solution found so far; a good initial limit prunes from the very beginning.
  • Bounds must be optimistic, cheap and tight. With f=g+hf = g + hf=g+h and an admissible hhh, best-first branch and bound is the A* algorithm.
  • In the worst case it explores an exponential number of nodes, like backtracking: a good heuristic changes the practical behavior, not the theoretical complexity.
