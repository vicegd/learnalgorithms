Exercises: Backtracking and Branch and Bound

These exercises review the four lessons of the chapter. They are different from the seminar activities (paths, Hamiltonian cycles and the traveling salesman) and from the lab problems, which are left for those sessions. Try each one before reading its solution: the solutions are grouped at the end of the page.

Backtracking​

6.1. Balanced parentheses. Generate all the strings of nnn pairs of balanced parentheses (for n=3n = 3n=3: ((())), (()()), (())(), ()(()), ()()()). Design a backtracking algorithm that never generates an invalid prefix. How many solutions are there for n=4n = 4n=4? How many nodes does your tree have, compared with generating every string of 2n2n2n parentheses and checking at the end?

6.2. Derangements. A derangement is a permutation in which no element stays in its original position (for example, a secret Santa where nobody gets themselves). Modify the permutation algorithm of the examples lesson to generate only derangements. How many are there for n=5n = 5n=5?

6.3. Splitting a text into words. Given the string catsanddog and the dictionary formed by the words cat, cats, and, sand and dog, find every way to split the string into dictionary words. Design a backtracking algorithm. In the worst case it is exponential; how can dynamic programming help?

6.4. Counting nodes. A backtracking algorithm decides, for each of nnn elements, whether to include it or not, and never prunes. How many nodes does its tree have? And an algorithm that generates every permutation of nnn elements? Give both counts for n=10n = 10n=10.

6.5. Which scheme? For each task, would you use the "first solution" or the "all solutions" scheme, and what would you keep during the search?

  • (a) Is there any way to place 10 queens on a 10×1010 \times 1010×10 board?
  • (b) How many solutions does a Sudoku have? (A well-posed Sudoku must have exactly one.)
  • (c) The cheapest way to assign 12 tasks to 12 agents.

Branch and bound​

6.6. Orders of exploration. In this tree, the number in parentheses is the estimate of each node (lower is better):

                A(8)
         ┌───────┴───────┐
       B(12)            C(9)
     ┌───┴───┐       ┌───┴───┐
   D(14)   E(12)   F(10)   G(11)
                     │
                   H(13)

Give the order in which the nodes are expanded with (a) depth-first search, (b) breadth-first search and (c) best-first search. (d) In best-first search, suppose that G turns out to be a solution with cost 11, and that the estimates are valid lower bounds. Which nodes are never expanded?

6.7. Knapsack trace. Solve the 0/1 knapsack with capacity W=16W = 16W=16 and four objects (weight, value): (2, 40), (5, 30), (10, 50), (5, 10), using best-first branch and bound with the fractional bound of the examples lesson. Show the bound of the root and the order in which nodes are expanded.

6.8. Valid bounds for assignment. In the task assignment problem (minimize the total cost), three lower bounds for a partial assignment are proposed. For each, say whether it is valid (never overestimates) and why:

  • (a) cost so far plus the minimum of each free column (task) over the free agents;
  • (b) cost so far plus the minimum of each free row (agent) over the free tasks;
  • (c) cost so far plus the maximum of (a) and (b).

6.9. Admissible heuristics. For the 8-puzzle, say whether each heuristic is admissible (never exceeds the true number of moves): (a) the number of misplaced tiles; (b) twice the number of misplaced tiles; (c) the Manhattan distance, counting the empty cell as a tile. Give a counterexample for those that are not.

6.10. Reachable or not? Without searching, decide which of these 8-puzzle boards can reach the goal 1 2 3 / 4 5 6 / 7 8 . (the dot is the empty cell, read row by row):

  • (a) 1 2 3 / 4 5 6 / 8 7 .
  • (b) 1 2 3 / 4 5 6 / 7 . 8
  • (c) 8 1 2 / . 4 3 / 7 6 5

6.11. Choosing the technique. For each problem, would you use backtracking or branch and bound? Justify briefly.

  • (a) List every valid coloring of a map with 4 colors.
  • (b) Find the shortest sequence of moves that solves a 15-puzzle.
  • (c) Find any solution of a Sudoku on a device with very little memory.
  • (d) Find the cheapest assignment of 20 tasks, given a good lower bound.

Solutions​

6.1. Build the string character by character, keeping the number of opening (o) and closing (c) parentheses used. An opening parenthesis can be added if o < n; a closing one only if c < o (otherwise the prefix would have more closings than openings).

void generate(String s, int o, int c, int n) {
    if (s.length() == 2 * n) {
        System.out.println(s);
        return;
    }
    if (o < n) generate(s + "(", o + 1, c, n);
    if (c < o) generate(s + ")", o, c + 1, n);
}

There are 14 solutions for n=4n = 4n=4 (the Catalan numbers: 1, 2, 5, 14, 42, ...). Our implementation generated 64 nodes, against the 511 nodes of the full binary tree of height 8 that generates all 28=2562^8 = 25628=256 strings before checking them. For n=10n = 10n=10: 16,796 solutions, 82,499 nodes, against more than 2 million.

6.2. Add one condition to the candidates: element iii cannot be placed in position kkk if i=ki = ki=k.

for (int i = 0; i < n; i++)
    if (!used[i] && i != level) { ... }

For n=5n = 5n=5 there are 44 derangements, out of 5!=1205! = 1205!=120 permutations; our tree had 147 nodes. In general, the proportion of derangements tends to 1/e≈36.8%1/e \approx 36.8\%1/e≈36.8%: the probability that nobody gets themselves in a random secret Santa is about 37% whatever the number of people.

6.3. At each position iii, try every dictionary word that starts there, and recurse from the end of the word. A solution is reached at the end of the string.

void split(String s, int i, List<String> words) {
    if (i == s.length()) {
        System.out.println(String.join(" ", words));
        return;
    }
    for (int j = i + 1; j <= s.length(); j++)
        if (dictionary.contains(s.substring(i, j))) {
            words.add(s.substring(i, j));
            split(s, j, words);
            words.remove(words.size() - 1);
        }
}

There are 2 solutions: cat sand dog and cats and dog. The number of splittings can be exponential (with aaaa...a and the dictionary with the words a and aa, it grows like the Fibonacci numbers), and then no algorithm can list them faster. But if we only need to know whether a splitting exists, the question "can the suffix from iii be split?" has only nnn distinct subproblems: storing their answers (memoization) or filling a table from the end gives an O(n2)O(n^2)O(n2) dynamic programming algorithm (plus the cost of the dictionary lookups). Memoization also prunes the backtracking search: a position known to be a dead end is not explored again.

6.4. A binary tree of height nnn has 1+2+4+⋯+2n=2n+1−11 + 2 + 4 + \dots + 2^n = 2^{n+1} - 11+2+4+⋯+2n=2n+1−1 nodes: 2,047 for n=10n = 10n=10. The permutation tree has 1+n+n(n−1)+⋯+n!1 + n + n(n-1) + \dots + n!1+n+n(n−1)+⋯+n! nodes, less than e⋅n!e \cdot n!e⋅n!: for n=10n = 10n=10, 9,864,101 nodes. (This is exactly the number of calls counted for the task assignment without pruning in the examples lesson.)

6.5.

  • (a) First solution, with a found flag: we only need to know whether one exists (and it does: every n≥4n \ge 4n≥4 has solutions).
  • (b) All solutions, with a counter. In practice, we can stop as soon as the counter reaches 2: that is enough to know that the Sudoku is not well posed.
  • (c) All solutions, keeping the best assignment found so far and its cost, which is also used to prune.

6.6.

  • (a) Depth-first: A, B, D, E, C, F, H, G.
  • (b) Breadth-first: A, B, C, D, E, F, G, H.
  • (c) Best-first: A (8), C (9), F (10), G (11), B (12), E (12), H (13), D (14). After expanding F, its child H (13) enters the queue but waits behind G and B. Between B and E, both with 12, B goes first because E does not exist until B is expanded.
  • (d) Once G gives a solution of cost 11, every live node with estimate 11 or more can be discarded: B, D, E and H are never expanded. Only A, C, F and G are.

The optimum is objects 1 and 3, value 90 (weight 12). The most promising branch (objects 1 and 2) looked best until the end, but its true best value was only 80.

6.8.

  • (a) Valid: each free task will be done by some free agent, at least at the cheapest cost of its column. This is the bound of the lesson.
  • (b) Valid, by the same argument applied to agents: each free agent will do some free task, at least at the cheapest cost of its row.
  • (c) Valid: if two values are both lower bounds, their maximum is also a lower bound, and it is tighter (better) than either. It costs twice as much to compute.

6.9.

  • (a) Admissible: each misplaced tile needs at least one move.
  • (b) Not admissible: the board 1 2 3 / 4 5 6 / 7 . 8 has one misplaced tile and is solved in one move, but the heuristic gives 2.
  • (c) Not admissible: on the same board, the tiles contribute 1 (the 8) and the empty cell contributes 1 more (it is one column away from its place), so the heuristic gives 2 for a board solved in 1 move. That is why the empty cell must not be counted.

6.10. For the 3 × 3 board, the goal is reachable if and only if the number of inversions among the 8 tiles (ignoring the empty cell) is even.

  • (a) The tiles in order are 1 2 3 4 5 6 8 7: one inversion (8, 7). Odd: not reachable. This is the famous puzzle with which Sam Loyd, in its 15-puzzle version, offered a prize that nobody could claim.
  • (b) 1 2 3 4 5 6 7 8: no inversions. Reachable (in one move).
  • (c) 8 1 2 4 3 7 6 5: the 8 forms 7 inversions, (4, 3) one more, and among 7 6 5 there are 3. In total 11, odd: not reachable.

6.11.

  • (a) Backtracking: every solution must be listed, so the whole tree is explored anyway, and backtracking uses much less memory.
  • (b) Branch and bound (A*) with priority g+hg + hg+h and the Manhattan distance: it finds the shortest solution, while depth-first search could get lost in very long paths.
  • (c) Backtracking: it only stores the current path. Constraint pruning and choosing the cell with fewest candidates first make it fast for Sudoku.
  • (d) Branch and bound: with a good bound and a best-first order, it can discard most of the 20!≈2.4×101820! \approx 2.4 \times 10^{18}20!≈2.4×1018 assignments.
