# Proofs: Backtracking and Branch and Bound

Backtracking and branch and bound are **exact** methods: they promise to find every solution, or the optimal one. That promise depends on the pruning being **safe**, that is, never discarding a branch that contains what we are looking for. This page proves when that is the case, and proves the specific facts used in the examples.

***

## Backtracking finds every solution

**Claim.** The "all solutions" scheme of [backtracking](./01-backtracking.mdx#general-schemes) processes every solution of the tree of states, provided that the feasibility test only rejects partial solutions that cannot be completed into a solution.

*Proof.* Without pruning, the recursion visits every node of the tree: by induction on the height of a subtree, a call on its root makes one recursive call per child, and each child call visits its whole subtree. With pruning, a child is skipped only if the test rejects it, and by hypothesis then no solution lies in its subtree. So every node that is an ancestor of a solution is visited, and in particular every solution is reached. $\blacksquare$

The "first solution" scheme visits the same nodes in the same order until the first solution, and stops there. If the tree has no solution, it explores everything that is not pruned, so it correctly reports that there is none.

**Termination.** If every branch of the tree is finite (every path from the root has a bounded length, for example $n$ decisions), the search terminates. This is not automatic in problems where states can repeat, such as sliding puzzles: there, repeated states must be detected, or the depth limited.

***

## Bound pruning never loses the optimum

**Claim.** In a minimization problem, if $\hat{c}(x)$ is a **lower bound** (no solution in the subtree of $x$ costs less than $\hat{c}(x)$), and $U$ is the cost of a solution already found, then discarding $x$ when $\hat{c}(x) \ge U$ never removes a solution cheaper than $U$.

*Proof.* Every solution $s$ in the subtree of $x$ satisfies $\mathrm{cost}(s) \ge \hat{c}(x) \ge U$. So none of them is better than the solution we already have. $\blacksquare$

Two consequences:
- The bound must be a true lower bound. If it can exceed the real cost of the best solution below $x$, the argument breaks, and the optimum can be pruned.
- The simplest bound is the **cost accumulated so far** when costs are non-negative, as in the [task assignment by backtracking](./02-backtracking-examples.mdx#task-assignment): adding more decisions can only increase the cost. Better bounds also estimate the cost still to come.

For **maximization** everything is mirrored: an upper bound $\hat{v}(x)$, and $x$ is discarded when $\hat{v}(x) \le$ the best value found.

***

## The bounds used in the examples are valid

**Task assignment.** The bound of the [B&B example](./04-branch-and-bound-examples.mdx#task-assignment) is the cost so far plus, for each free task, the minimum cost in its column among the free agents.

*Proof.* In any complete assignment that extends the current one, each free task $j$ is done by some free agent $i$, at cost $C[i][j] \ge \min_{\text{free } i'} C[i'][j]$. Adding over the free tasks, the remaining cost is at least the sum of the column minima. $\blacksquare$

The same argument works with the row minima (each free agent does some free task), and the maximum of two lower bounds is also a lower bound.

**0/1 knapsack.** The bound of the [knapsack example](./04-branch-and-bound-examples.mdx#01-knapsack) is the value obtained by filling the remaining capacity greedily by value per weight, allowing a fraction of the last object.

*Proof.* Any way of completing the current selection with whole objects is, in particular, a valid solution of the **fractional** knapsack on the remaining objects and capacity. The greedy algorithm solves the fractional knapsack [optimally](../03-algorithm-design-paradigms/proofs.mdx#the-fractional-knapsack-highest-value-per-weight-first), so its value is at least the value of any completion with whole objects. It is therefore an upper bound. $\blacksquare$

## Best-first branch and bound stops at the optimum

**Claim.** In the [general scheme](./03-branch-and-bound.mdx#general-scheme), with a valid lower bound in every node and the exact cost in every solution, when the loop stops (the heap is empty or its best estimate is at least $U$), `bestNode` is an optimal solution (or there is none, if $U$ is still the initial limit and no solution was found).

*Proof.* At any moment, every unexplored solution lies in the subtree of some live node in the heap, or of a node that was pruned. Pruned nodes contain no solution cheaper than the value of $U$ at the moment they were pruned, which is at least the final $U$ (since $U$ only decreases). When the loop stops, every live node has estimate at least $U$, because the heap returns its minimum, so their subtrees contain nothing cheaper than $U$ either. So no solution is cheaper than $U$, and `bestNode` has cost $U$. $\blacksquare$

The order of the heap affects **how fast** the bound $U$ improves, and therefore how much is pruned, but not the correctness.

***

## A\* with an admissible heuristic finds an optimal path

Consider a search where each node $x$ has $g(x)$, the cost of the path from the start to $x$, and $h(x)$, an estimate of the cost from $x$ to the goal. The live nodes are ordered by $f(x) = g(x) + h(x)$.

**Claim.** If $h$ is **admissible** ($h(x) \le h^*(x)$, the true remaining cost, for every $x$, and in particular $h = 0$ at the goal), the first goal node extracted from the priority queue has minimum cost.

*Proof.* Let $C^*$ be the cost of an optimal solution, and suppose that a goal node $t$ with cost $g(t) \gt C^*$ is extracted first. At that moment, some node $x$ on an optimal path is still live (the start node is on it, and each time a node of the path is expanded, its successor on the path enters the queue). For that node, $g(x)$ is its cost along the optimal path, so

$$
f(x) = g(x) + h(x) \le g(x) + h^*(x) = C^* \lt g(t) = f(t)
$$

The queue would have extracted $x$ before $t$: a contradiction. $\blacksquare$

The proof assumes that a node reached later by a cheaper path is updated or reinserted (as in the 8-puzzle measurements of the lessons). Ordering by $h$ alone breaks the inequality, because $g$ is missing, which is why the "greedy" version found much longer solutions in the [measurements](./04-branch-and-bound-examples.mdx#ordering-the-live-nodes-g--h).

## The puzzle heuristics are admissible

**Misplaced tiles.** Each tile that is not in its final cell must move at least once, and each move moves one tile. So the number of moves is at least the number of misplaced tiles. $\blacksquare$

**Manhattan distance.** Each move slides one tile to an adjacent cell, which changes that tile's Manhattan distance by exactly 1 and leaves the others unchanged. So the total distance decreases by at most 1 per move, and reaching total distance 0 needs at least as many moves as the initial distance. $\blacksquare$

Both arguments count only the numbered tiles. If the empty cell is counted, the first argument fails: a board solved in one move can have two "misplaced" pieces (the tile and the gap).

## The parity condition of the 15-puzzle

The [reachability test](./04-branch-and-bound-examples.mdx#reachability-test) says that the goal can be reached if and only if $\sum \text{smaller}(i) + x$ is even. We prove that the condition is **necessary**: if the sum is odd, no sequence of moves reaches the goal.

*Proof.* Read the board row by row, with the empty cell as tile 16. Then $\sum \text{smaller}(i)$ is the number of inversions of that sequence, and $x$ indicates the color of the empty cell on a checkerboard. Every move swaps the empty cell with a neighbor:

- A **horizontal** move swaps two adjacent elements of the sequence: the number of inversions changes by exactly 1.
- A **vertical** move swaps the empty cell with the tile 4 positions before or after it in the sequence, with 3 tiles in between. The moving tile passes over those 3 tiles (3 pairs change order), the empty cell passes over the same 3 tiles in the other direction (3 more pairs), and the pair formed by the moving tile and the empty cell also changes order. In total, 7 pairs change order: an odd number.

So every move changes the parity of the number of inversions. Every move also changes the color of the empty cell's square ($x$ flips between 0 and 1). The parity of the sum therefore never changes. The goal has 0 inversions and the empty cell on an unshaded square, so its sum is 0, even. A board with an odd sum can never reach it. $\blacksquare$

The converse (every board with an even sum can reach the goal) is also true, but its proof is constructive and longer: it shows how to move any tile to its place without disturbing the ones already placed. It was published by Johnson and Story in 1879.
