A.8. The step from n=1n = 1n=1 to n+1=2n + 1 = 2n+1=2 fails. With 2 horses, removing the first leaves the second and removing the last leaves the first: the two groups have no horse in common, so nothing connects their colors. The argument "both groups share the horses in the middle" needs n≥2n \ge 2n≥2, and the base case only covers n=1n = 1n=1. The lesson: the inductive step must work for every nnn from the base case on, including the first one.

A.9. Invariant: gcd⁡(a,b)\gcd(a, b)gcd(a,b) is the same before and after each iteration, equal to the gcd of the original values. It holds because gcd⁡(a,b)=gcd⁡(b,a mod b)\gcd(a, b) = \gcd(b, a \bmod b)gcd(a,b)=gcd(b,amodb): any number that divides aaa and bbb also divides a mod b=a−qba \bmod b = a - q bamodb=a−qb, and conversely. When the loop ends, b=0b = 0b=0 and gcd⁡(a,0)=a\gcd(a, 0) = agcd(a,0)=a, so the result is correct. It terminates because bbb is a non-negative integer that strictly decreases at each iteration (a mod b<ba \bmod b \lt bamodb<b), so it must reach 0. In fact it decreases fast: every two iterations the value at least halves, so the loop runs O(log⁡b)O(\log b)O(logb) times.
