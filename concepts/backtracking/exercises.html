Exercises: Backtracking

These exercises review the two lessons on backtracking. They are different from the seminar activities (paths, Hamiltonian cycles and the traveling salesman) and from the lab problems, which are left for those sessions. Try each one before reading its solution: the solutions are grouped at the end of the page.

7.1. Balanced parentheses. Generate all the strings of nnn pairs of balanced parentheses (for n=3n = 3n=3: ((())), (()()), (())(), ()(()), ()()()). Design a backtracking algorithm that never generates an invalid prefix. How many solutions are there for n=4n = 4n=4? How many nodes does your tree have, compared with generating every string of 2n2n2n parentheses and checking at the end?

7.2. Derangements. A derangement is a permutation in which no element stays in its original position (for example, a secret Santa where nobody gets themselves). Modify the permutation algorithm of the examples lesson to generate only derangements. How many are there for n=5n = 5n=5?

Solution to 7.2 ↓

7.3. Splitting a text into words. Given the string catsanddog and the dictionary formed by the words cat, cats, and, sand and dog, find every way to split the string into dictionary words. Design a backtracking algorithm. In the worst case it is exponential; how can dynamic programming help?

Solution to 7.3 ↓

7.4. Counting nodes. A backtracking algorithm decides, for each of nnn elements, whether to include it or not, and never prunes. How many nodes does its tree have? And an algorithm that generates every permutation of nnn elements? Give both counts for n=10n = 10n=10.

Solution to 7.4 ↓

7.5. Which scheme? For each task, would you use the "first solution" or the "all solutions" scheme, and what would you keep during the search?

  • (a) Is there any way to place 10 queens on a 10×1010 \times 1010×10 board?
  • (b) How many solutions does a Sudoku have? (A well-posed Sudoku must have exactly one.)
  • (c) The cheapest way to assign 12 tasks to 12 agents.

7.1. Build the string character by character, keeping the number of opening (o) and closing (c) parentheses used. An opening parenthesis can be added if o < n; a closing one only if c < o (otherwise the prefix would have more closings than openings).

void generate(String s, int o, int c, int n) {
    if (s.length() == 2 * n) {
        System.out.println(s);
        return;
    }
    if (o < n) generate(s + "(", o + 1, c, n);
    if (c < o) generate(s + ")", o, c + 1, n);
}

There are 14 solutions for n=4n = 4n=4 (the Catalan numbers: 1, 2, 5, 14, 42, ...). Our implementation generated 64 nodes, against the 511 nodes of the full binary tree of height 8 that generates all 28=2562^8 = 25628=256 strings before checking them. For n=10n = 10n=10: 16,796 solutions, 82,499 nodes, against more than 2 million.

7.2. Add one condition to the candidates: element iii cannot be placed in position kkk if i=ki = ki=k.

for (int i = 0; i < n; i++)

For n=5n = 5n=5 there are 44 derangements, out of 5!=1205! = 1205!=120 permutations; our tree had 147 nodes. In general, the proportion of derangements tends to 1/e≈36.8%1/e \approx 36.8\%1/e≈36.8%: the probability that nobody gets themselves in a random secret Santa is about 37% whatever the number of people.

7.3. At each position iii, try every dictionary word that starts there, and recurse from the end of the word. A solution is reached at the end of the string.

void split(String s, int i, List<String> words) {
    if (i == s.length()) {
        System.out.println(String.join(" ", words));
        return;
    }
    for (int j = i + 1; j <= s.length(); j++)
        if (dictionary.contains(s.substring(i, j))) {
            words.add(s.substring(i, j));
            split(s, j, words);
            words.remove(words.size() - 1);
        }
}

There are 2 solutions: cat sand dog and cats and dog. The number of splittings can be exponential (with aaaa...a and the dictionary with the words a and aa, it grows like the Fibonacci numbers), and then no algorithm can list them faster. But if we only need to know whether a splitting exists, the question "can the suffix from iii be split?" has only nnn distinct subproblems: storing their answers (memoization) or filling a table from the end gives an O(n2)O(n^2)O(n2) dynamic programming algorithm (plus the cost of the dictionary lookups). Memoization also prunes the backtracking search: a position known to be a dead end is not explored again.

7.4. A binary tree of height nnn has 1+2+4+⋯+2n=2n+1−11 + 2 + 4 + \dots + 2^n = 2^{n+1} - 11+2+4+⋯+2n=2n+1−1 nodes: 2,047 for n=10n = 10n=10. The permutation tree has 1+n+n(n−1)+⋯+n!1 + n + n(n-1) + \dots + n!1+n+n(n−1)+⋯+n! nodes, less than e⋅n!e \cdot n!e⋅n!: for n=10n = 10n=10, 9,864,101 nodes. (This is exactly the number of calls counted for the task assignment without pruning in the examples lesson.)
