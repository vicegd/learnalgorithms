OpenAPI 3.1 Reference

learnalgorithms.dev API

Privacy-preserving REST API written with the Python standard library and SQLite. Stores no personal data or IP addresses. Click any endpoint below to inspect its schema or try live public requests.

https://api.learnalgorithms.devDownload openapi.yaml ↓

Public endpoints

GET/healthLiveness check

Returns 200 OK when the API container is healthy and ready to serve requests.

Example Request
curl -i https://api.learnalgorithms.dev/health
Responses
200 OK — {"status":"ok"}
GET/popularMost read lessons of the last 7 days

Fetched server-to-server from Matomo and cached in memory for 15 minutes. Degrades gracefully to an empty list if Matomo is unreachable.

Example Request
curl -i https://api.learnalgorithms.dev/popular
Responses
200 OK — {"pages":[{"page":"...","visits":42}]}
GET/feedback/summaryAggregated helpfulness votes for one lesson

Query parameter: page (e.g. /concepts/sorting/quicksort). Rate-limited per IP.

Example Request
curl -i "https://api.learnalgorithms.dev/feedback/summary?page=/concepts/sorting/quicksort"
Responses
200 OK — {"page":"...","helpful":10,"notHelpful":1}400 Bad Request — invalid page429 Too Many Requests
POST/feedbackSubmit anonymous lesson feedbackOrigin: learnalgorithms.dev

Stores a helpful/not-helpful vote with an optional comment (max 500 chars). Protected against bots with a honeypot field, minimum time on page (3 s), and one vote per page, client, and day.

Example JSON Body
{
  "page": "/concepts/sorting/quicksort",
  "helpful": true,
  "comment": "The partition trace made it click!",
  "elapsed": 12000,
  "website": "",
  "client": "11111111-1111-4111-8111-111111111111"
}
Responses
201 Created — stored200 OK — already voted today202 Accepted — bot check400 Bad Request403 Forbidden429 Too Many Requests
POST/eventsRecord anonymous student/usage telemetry eventsOrigin: learnalgorithms.dev

Accepts a single event or a batch (max 20 events, 4 KB body). Allowed eventType values: page_view, page_leave, lesson_complete, lesson_uncomplete, cheat_sheet_filter, cheat_sheet_compare, visualizer_interact, search, details_open, resource_click.

Example JSON Body
{
  "events": [
    {
      "sessionId": "11111111-1111-4111-8111-111111111111",
      "eventType": "page_leave",
      "page": "/concepts/sorting/quicksort",
      "durationMs": 45000,
      "scrollPct": 85
    }
  ]
}
Responses
201 Created — {"status":"stored","count":1}400 Bad Request403 Forbidden429 Too Many Requests

Integrations & Webhooks

POST/webhooks/githubReceive GitHub issue eventsHMAC-SHA256

Verifies X-Hub-Signature-256 in constant time using GITHUB_WEBHOOK_SECRET and stores issue events idempotently by X-GitHub-Delivery.

Responses
200 OK — ping202 Accepted — ignored204 No Content — stored400 Bad Request401 Unauthorized

Admin & Teaching Innovation Analytics

GET/admin/statsAggregated learning analytics summaryBearer Token

Query parameter: days (1–365, default 30). Returns totals (events, sessions, activeDays), events by type, top pages with average duration and scroll depth, lesson completions, and daily activity.

Example Request
curl -H "Authorization: Bearer <ADMIN_TOKEN>" "https://api.learnalgorithms.dev/admin/stats?days=30"
Responses
200 OK — JSON report400 Bad Request401 Unauthorized
GET/admin/eventsExport anonymized telemetry events (JSON or CSV)Bearer Token

Query parameters: days (1–365, default 30), limit (1–5000, default 500), format (json | csv). With format=csv downloads learnalgorithms-events.csv ready for Excel, R, SPSS, or Python.

Example Request
curl -H "Authorization: Bearer <ADMIN_TOKEN>" "https://api.learnalgorithms.dev/admin/events?days=30&format=csv" -o learnalgorithms-events.csv
Responses
200 OK — application/json or text/csv400 Bad Request401 Unauthorized
GET/admin/feedbackLatest qualitative feedback votes and commentsBearer Token

Returns the latest 200 feedback entries stored in SQLite with Cache-Control: no-store.

Example Request
curl -H "Authorization: Bearer <ADMIN_TOKEN>" "https://api.learnalgorithms.dev/admin/feedback"
Responses
200 OK — {"feedback":[...]}401 Unauthorized
GET/admin/issuesLatest GitHub issue webhook eventsBearer Token

Example Request

Responses
200 OK — {"issues":[...]}401 Unauthorized
